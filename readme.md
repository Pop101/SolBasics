# SolBasics

A shelf of Solidity contracts and libraries for studying access control, token interaction and contract math. Several files intentionally adapt earlier designs.

[![Open GitHub issues](https://img.shields.io/github/issues/Pop101/SolBasics?style=flat-square)](https://github.com/Pop101/SolBasics/issues)

## Overview

Browse [`contracts`](contracts) and [`libraries`](libraries) for examples, and [`tests`](tests) for the checked-in Solidity test source. The files are experiments, not a vetted standard library.

## Technologies

- [OpenZeppelin Contracts](https://github.com/OpenZeppelin/openzeppelin-contracts) is referenced by the ERC-20 test.
